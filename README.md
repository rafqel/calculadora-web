---

## 📖 About

This is a personal project developed to sharpen my front-end skills, specifically focusing on DOM manipulation, event handling, and responsive design. 

The application consists of a web-based calculator that performs basic arithmetic operations using pure HTML, CSS, and JavaScript, without relying on any external frameworks or libraries.

---

## ✨ Features

- ➕ **Basic Operations:** Addition, subtraction, multiplication, and division.
- 🔢 **Decimal Support:** Handles floating-point numbers accurately.
- 🧹 **Clear Functions:** Buttons to clear the entire display (AC) or delete the last character (DEL).
- 📱 **Responsive Design:** Optimized layout that works perfectly on both desktop and mobile devices.
- ⌨️ **Keyboard Support:** Allows input using the physical keyboard for a better user experience.

---

## 🛠️ Technologies

- **HTML5** – Semantic structure.
- **CSS3** – Styling and grid layout for the buttons.
- **JavaScript (ES6)** – Logic, DOM manipulation, and event handling.

---

## ⚙️ How to Use

1. Clone the repository:
   `git clone https://github.com/rafqel/web-calculator.git`

2. Navigate to the project folder.

3. Open the `index.html` file directly in your browser, or run it using **Live Server** in VS Code.
